Tunevia Development Roadmap
===========================

Approved Features (20)
----------------------
1. Spotify/Apple Music playlist import functionality.
2. Discord Rich Presence integration showing current track.
3. Mini-player overlay mode (Always on top, compact UI).
4. Podcast subscription, management, and playback support.
5. Built-in Equalizer presets (Pop, Rock, Bass Boost, etc.).
6. Last.fm Scrobbling integration.
7. Seamless gapless playback and crossfading between tracks.
8. Local media folder scanning and playback.
9. SponsorBlock integration to automatically skip YouTube sponsor segments.
10. Automatic lyrics translation to user's locale.
11. Scheduled downloads (e.g., download playlists during off-peak hours).
12. Advanced ID3 tag editor for downloaded MP3s.
13. Chromecast / DLNA casting support.
14. Sleep timer to auto-stop playback or close the app.
15. Customizable themes with community theme sharing.
16. Media key and Windows SMTC (System Media Transport Controls) integration.
17. Collaborative playlists via a lightweight shared backend.
18. Offline mode toggle for browsing history and downloads without network errors.
19. Voice commands mapping for hands-free basic control.
20. Smart Playlists that automatically group songs based on play count or release year.
